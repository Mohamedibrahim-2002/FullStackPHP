# ⌚ WatchStore - Watch Gallery & Showcase

A web application designed to showcase a curated collection of premium watches (Rolex, Tissot, Movado, Timex, etc.), explore real-time price comparisons across retailers, and build out a full-stack e-commerce experience using PHP, JavaScript, CSS, and HTML.

---

## 📖 Overview

The **WatchStore** project is an interactive watch gallery and store platform. The goal is to provide watch enthusiasts and shoppers with a visual showcase of luxury and everyday timepieces, detailed specifications, and retailer price comparisons.

This repository tracks the step-by-step development from front-end layout prototypes to a full-stack dynamic PHP-powered web application.

---

## ✨ Features

- **Watch Showcase & Gallery**: High-resolution imagery of popular brands including Rolex, Movado, Tissot, and Timex.
- **Price Comparison Concept**: Compare real-time market value against various retail pricing.
- **Modern Responsive Design**: Custom CSS styling with full-screen background aesthetics and card overlays.
- **Dynamic Interactivity**: JavaScript integration for future dynamic filtering, modal previews, and cart interactions.
- **Extensible Architecture**: Structured to easily integrate PHP backend logic, database management (MySQL), and REST APIs.

---

## 🛠️ Tech Stack

- **Frontend**:
  - HTML5 (Semantic Markup)
  - CSS3 (Custom layout styling & animations)
  - JavaScript (ES6+ Client-side logic)
- **Backend (In Development)**:
  - PHP (Server-side scripting & data handling)
  - MySQL / Relational Database (Catalog & user management)

  - Apache / XAMPP / PHP Built-in Server

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Edge, Firefox, etc.)
- *(Optional)* [PHP](https://www.php.net/) (v8.0+) or a local server suite like [XAMPP](https://www.apachefriends.org/) / [WAMP](https://www.wampserver.com/) for running PHP backend features.

### Quick Start (Static Frontend)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ibrahim402/FullStackPHP.git
   cd FullStackPHP
   ```

2. **Open in browser:**
   - Double-click `WatchStore/index.html` or open it with the **Live Server** extension in VS Code.

### Running with PHP Server

If running with a local PHP environment:

```bash
cd WatchStore
php -S localhost:8000
```
Then visit `http://localhost:8000` in your browser.
